# SkinHealthAI 👨‍⚕️📱

Um aplicativo Android desenvolvido com **Jetpack Compose** para auxiliar na análise de imagens da pele. O app permite que usuários se cadastrem, façam login e acessem funcionalidades de captura e visualização de imagens.

## 📦 Tecnologias Utilizadas

- Kotlin
- Jetpack Compose
- Material 3
- Navigation Compose
- ViewModel
- Arquitetura em pacotes: `screens`, `viewmodel`, `theme`, `components`
